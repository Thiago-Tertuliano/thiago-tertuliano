## Sobre

Desenvolvedor backend focado em **Go**, com sistemas ETL, APIs REST e pipelines de dados em produção.
Trabalho com arquitetura de serviços, concorrência, observabilidade e integrações — do desenho ao deploy.

Na **3CON**, escrevo Go em produção (vim de TypeScript) e atuo também no front com **Angular** e **React**. Um resultado que me marcou: um ETL que saiu de **~2h30 para ~5 minutos** — ganho acima de 96%, com jobs concorrentes, batches e logs estruturados por etapa.

Cursando **Análise e Desenvolvimento de Sistemas**. Construo projetos reais com DDD, testes, CI e documentação.

- 🔧 Stack principal: Go · TypeScript · Angular · Vue.js · C# / .NET · PostgreSQL · Node.js

- Formulários reativos: validação, estados de erro, binding e **change detection**
- Integração **front ↔ APIs .NET** (contratos HTTP, controllers, filtros, payloads)

- Code review, PRs e fluxo de branch em time (não é projeto solo)

Isso convive com o trabalho em **Go + PostgreSQL + React** nos demais produtos internos da 3CON (ETL, APIs e observabilidade).
